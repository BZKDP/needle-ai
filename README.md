# needle-ai — поиск еле заметной иглы на фото (с нуля)

Учебно-рабочий проект: обучаем локальную нейросеть находить тонкую, почти
незаметную иглу на фотографии. Строим «с нуля», чтобы понять механику.

## Два пути

- **Путь А — понять механику** (`pathA_scratch/`)
  Крошечная свёрточная сеть на чистом PyTorch, написанная руками.
  Работает на CPU. Учимся на СИНТЕТИЧЕСКИХ иглах, пока нет реальных фото.
  Цель — увидеть каждую шестерёнку: данные → слои → потеря → обучение → предсказание.

- **Путь Б — рабочий детектор** (`pathB_yolo/`)
  Дообучаем YOLO на 1000 реальных пар фото. Тренируем в Google Colab (бесплатный GPU),
  готовую модель забираем файлом и запускаем локально на этом ПК.

## План

2. [x] Собрать окружение (PyTorch CPU)

4. [ ] Извлечь координаты иглы из парных фото (авто-разметка)
5. [ ] **Путь Б**: подготовить датасет в формате YOLO → обучить в Colab → инференс локально

## Быстрый старт (Путь А)

```powershell
# 1. сгенерировать 2000 синтетических картинок с иглой + метки
python pathA_scratch/generate_synthetic.py

# 2. обучить мини-сеть (CPU, несколько минут)
python pathA_scratch/train.py

# 3. посмотреть, как сеть находит иглу на новых картинках
python pathA_scratch/predict.py
```

## Словарь (чтобы не путаться)

- **датасет** — набор примеров для обучения (картинки + правильные ответы = «метки»).
- **метка (label)** — правильный ответ: где игла. У нас это координаты (x, y) центра иглы.
- **train / val / test** — учим на train, проверяем на val, финальный экзамен на test.
- **модель / сеть** — функция с настраиваемыми числами («весами»), превращает картинку в ответ.
- **обучение** — процесс подгонки весов, чтобы ответы совпадали с метками.
- **функция потерь (loss)** — насколько ответ модели далёк от правильного; её минимизируем.
- **эпоха (epoch)** — один полный проход по всему датасету во время обучения.
- **инференс** — использование обученной модели на новых данных.
